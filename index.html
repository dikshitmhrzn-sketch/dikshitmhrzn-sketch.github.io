03. Projects

Selected work — built as complete systems rather than isolated pages.

Nepal Hub

A Nepal-focused digital platform that brings tools, a daily quiz, a student hub, jobs, a business directory, offers and events into one place. The React client talks to an ASP.NET Core API over HTTP; MySQL runs through EF Core, and a Flutter mobile app reuses the same endpoints. Core modules are live with seeded content.

ReactTypeScriptASP.NET CoreMySQLFlutter

WardSociety

A community-management application for local wards: public notices, services and businesses, a resident portal for applications, complaints and appointments, and separate admin consoles per ward with role-based access. Built with the Next.js App Router, Prisma and MySQL; later phases are still being verified.

Next.jsTypeScriptPrismaMySQL

Futsal Matchmaking

A futsal matchmaking and management system: find courts and opponents, book slots, run tournaments, manage teams, message other players and track rankings. Separate player, owner and admin panels, a PHP/MySQL backend hardened by a security audit pass, and a Flutter mobile app sharing the same API.

PHPMySQLFlutter

Restaurant Management System

A restaurant website with menu browsing, table reservations, order placement and tracking, favourites and payment initiation. Written in PHP with MySQL, and written up in a blog post covering how it was built and hosted on free hosting.

PHPMySQL
Source Live site

Hospital Management System

A healthcare dashboard focused on patients, doctors, appointments and medical reports: upload flow, an AI analysis step, a report progress tracker and an appointment view. This is a frontend prototype — static HTML, CSS and JavaScript with Bootstrap; the backend is not wired up yet.

HTMLCSSJavaScriptBootstrap
